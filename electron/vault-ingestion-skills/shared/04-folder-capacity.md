# Folder capacity

- Maximum **10 note files per folder**, excluding the folder overview file.
- Overview files matching `*-overview.md` (and legacy `overview.md`) do **not** count toward the limit.
- If a folder already has 10 notes, place new notes in a subfolder (e.g. `concepts/part-2/`) and update the parent overview links.
- The **Current vault structure** section in the system prompt lists per-folder note counts and existing paths — read it before every plan and respect limits when planning paths.
